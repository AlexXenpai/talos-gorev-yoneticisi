# `.agents` Klasörü (Antigravity Proje Özelleştirme Dizini)

Bu klasör, **Google Antigravity** yapay zeka ajanının bu projede çalışırken otomatik olarak keşfettiği (`Auto-Discovery`) özelleştirme dizinidir:

- **`rules/talos-python-kurallari.md`:** Ajanın bu projede kod yazarken uyması gereken kuralları (50–100 satır sınırı, en az 2 class, en az 4 fonksiyon, PEP 8 uyumu) tanımlar.
- **`skills/talos-proje-denetimi/SKILL.md`:** Ajana TALOS 1. Hafta proje kriterlerini adım adım nasıl denetleyeceğini öğreten özel yetenek (skill) dosyasıdır.
